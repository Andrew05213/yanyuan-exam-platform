# 首次加载与公开资源

LAN 网关直接提供 `public/` 内的脚本、样式、JSON、SVG 和字体：按浏览器能力使用 Brotli 或 gzip，内容及压缩版本在进程内缓存，文件变更时失效，缓存总量限制为 16 MB。只处理最大 2 MB 的普通公开文件，范围请求和其他文件继续交给原服务。符号链接解析后仍须位于公开目录中。

带 `?v=` 的公开资源使用长期缓存，因此修改脚本或样式后，必须同步增加 `public/index.html` 中的版本号。题库 JSON 不带版本，使用 ETag 条件校验；文件变化后返回新内容，未变化时返回 304。

HTML、账户、私人档案、录音、原稿图片和所有 API 响应不进入这个静态缓存。登录身份及跨用户隔离沿用原网关与应用的校验。

首页预加载五个题库，登录状态与题库并行读取。加载时显示进度，30 秒未完成则提供刷新入口，不把未确认的登录状态当成访客身份。

反向代理应对现有 HTTPS 站点开启 HTTP/2，减少多份脚本及题库反复建立连接；无需新增公网端口或改变证书、上游地址。Nginx Proxy Manager 应保存站点的 HTTP/2 选项，而不只是临时修改生成文件。

验证：`node scripts/verify_public_assets.mjs` 检查压缩、缓存失效、路径边界和 API 排除；`node scripts/verify_startup.mjs` 检查并行加载及超时处理。现有页面与登录测试继续适用。
