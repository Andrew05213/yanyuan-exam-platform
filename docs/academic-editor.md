# 阶段04 专业学术笔记编辑器
基于 main d319593。阶段03已合并，PR #11 合并后主线 CI 的 Chromium 功能断言通过但临时目录清理 ENOTEMPTY；本草稿补充有界重试，不移除测试。等待该修复及新增功能完整 CI，用户本人审批后才可合并。禁止自动部署或使用生产数据。

原有私人笔记编辑器内增量增加编辑/分栏/预览、标题/粗体/斜体/引文/列表/代码/脚注、常用希腊字母、上下标与简单分式。安全 React 文本渲染，无 HTML 注入、外部图片或脚本。不是完整 CommonMark 或 LaTeX 引擎，复杂表达式显示源文。原始文本无转换保存、旧备份继续兼容。原有本机草稿默认保留；用户可在本次编辑开启停笔4秒后云保存，失败不连续重试，冲突仍使用已有版本检查和另存机制。历史仅记录标题和正文，不记录其它元数据，20个旧版本上限；读取按已登录所有者、no-store。恢复为当前编辑草稿，明确确认，关闭自动保存，手动保存形成新修订；不会倒退 revision 或自动发布。归档/回收站沿用原逻辑，真正删除笔记时清除快照。历史不向社区、AI、协作者或管理员额外开放。

新增迁移 0020，按版本顺序应用，禁止改旧迁移。部署前须在隔离环境测试触发器、备份兼容、自动保存与关闭/切换账号、并发、移动端分栏及预览、历史权限、恢复和生产升级。当前提交前仅执行纯格式函数断言；集成测试和完整 CI 由 GitHub运行，真实浏览器编辑器验收仍待完成。无生产部署。
