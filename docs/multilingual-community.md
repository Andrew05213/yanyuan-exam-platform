# 多语言研究社区（第二阶段）

- 研究入口保持在 /literature#community，原有日本作品、读书笔记、公开议题、批注、共享书目与权限不变。
- research-catalog.ts 是统一的可维护专题目录：六重点语种 × 六领域（36），另有六个基础语种（6）。英语是研究语言，并非北大保送语种声明。其他方向依据仓库当前备考名单，非当年官方招生确认。
- 条目有稳定 ID、语种、学科、专题名称、原创摘要、研究问题、检索词、版本、资料检索入口及类型。入口不代表已经读取或核验具体全文；不复制受版权保护作品。实际研究需要用户核对具体来源。
- 议题可从目录预填后由成员确认创建；私人笔记仍须保存、再次确认发布。旧议题分类为空，不伪造分类。新增 0027 迁移，服务器分页前按分类筛选，继续执行现有社区权限与治理过滤。
- 扩充时添加新条目和版本、核对机构入口；跨语言专题多对多关联、按具体来源版本/段落驱动 AI 出题属于第三阶段，尚未实现。
