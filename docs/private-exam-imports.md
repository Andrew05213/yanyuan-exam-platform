# 外部试卷私人导入
旧系统已有共享附件、本站训练卷JSON导入和作文本机OCR，但无从外部原件到私人笔试组卷库存的独立管道。新增0026、原件R2私有存储、SHA256按用户去重，8MB/份、30份/账号、10组/100题，出处必填、来源URL可选、原题号及每组原卷位置必填。支持TXT自动读取、结构化JSON(groups数组)、DOCX正文客户端限量解压、JPG/PNG本机中文英文OCR，PDF保留原件，并在浏览器使用同站PDF.js逐页取文，对没有文本层或仅有少量文字及图片的页面渲染后调用本机中英文OCR。单份上限120页、60000字、100道识别题。自动保存原页文字、解析提示、原题号及起始页至私人待审核草稿；刷新后可继续校对，人工确认后加入组卷库存。复杂公式、版面和表格需对照原件。自动解析仅保守支持编号四选一及显式答案；未知答案不补造，手工校对或使用JSON编辑其他既有题型。原卷无解析时明确标识，不伪造解析。资料合法私人使用确认，所有原件/草稿及已审核题目严格本人可见，不自动发布。人工核对后才进入DifficultyEngine既有库存，刷新及组卷前重新读取；来源随题组/题目保留，原件可下载核对。删除或撤回后不再进入新组卷；已保存的旧试卷为快照。源ID按原题号及题组稳定，组内重新排列可能改变组索引。无外部模型和第三方OCR传输。新增隔离D1/R2 API与真实浏览器文本导入、识别、审批、重新读取和删除测试；完整CI待核对。生产0026/R2配置仍需部署验证。

来源追踪补丁：普通非阅读题也在生成的试卷界面展示出处、原文件及原题号，并在Markdown输出保留。冲突答案自动清空、必须人工核对。浏览器回归额外构造真实组卷并核对来源显示与Markdown。最终验收以最新提交CI为准。
