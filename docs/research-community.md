# 研究社区

社区默认关闭。部署时，在应用服务的环境绑定中将 `RESEARCH_COMMUNITY_USER_IDS` 设为逗号分隔的受邀账号 ID。列表为空时，普通账号和管理员均无法进入社区。需要处理举报的管理员也要获邀。账号 ID 可从该账号的 `/api/session` 响应读取，公开注册流程照常使用。

受邀用户可在文学研习中进入「研究社区」。共享笔记只有社区成员能浏览。提交共享前须确认正文；后续修改私人笔记不会更新共享版本。归档或移入回收站的私人笔记不能再次发布，已共享的版本可从议题中手动撤回。

私人笔记及其 AI 助手仍在「日本读书笔记」模块。AI 分析需预览实际发送的材料和模型并确认。
