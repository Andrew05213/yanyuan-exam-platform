# 研究社区 · 第二阶段

基于第一阶段的多语种笔记功能。新增 `0013_research_community` 迁移；不修改既有 entries 或历史迁移。新表为空，旧笔记不会自动公开。

- 登录后进入 /literature 的「研究社区」。创建议题，打开议题，撰写独立笔记并在私人编辑器保存，再从当前议题选取笔记、检查完整预览和确认公开。相同议题可有多个用户的多篇独立笔记；同一笔记也可分别发布到多个议题。
- 私人 entries 继续按 user_id 隔离。共享表存放主动发布的快照；更新私人笔记不改变公开版，再次发布才更新并递增 revision。发布绑定用户、笔记编号、保存时间与议题，不接受客户端提供的正文或作者身份。
- 公开正文仅供已登录账号阅读，不返回真实邮箱或用户 ID，不自动公开作品编号、页码、标签、复习日期。昵称为每条公开笔记的匿名标识。撤回物理删除共享快照，不影响私人原稿，不能撤销别人已复制的内容。
- 议题与公开笔记分页；每账号最多创建30个议题、保留100条公开笔记。第一版没有删除议题、评论、私聊、跨语种 AI 搜索、举报审核或完整历史版本功能；revision 仅是当前发布版本序号。公开社区不应在缺乏审核、举报和封禁等安全机制时向陌生人扩张。
- 中国版继续使用现有 LAN 网关；只追加精确 API 白名单。正式部署前备份 D1、账号和配置，在独立数据库应用 0012、0013，重新构建文学入口，重启服务并用两个测试账号验收。不要使用生产账号测试。
- 新增 verify_research_community.mjs 使用隔离 Miniflare/D1，加入原 CI。另需实际 LAN 网关、手机端、搜索及撤回页面验收。未通过不得合并。
