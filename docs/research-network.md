# 研究关联与共享书目
追加迁移 0016，保持既有账号、私人笔记与公开版本机制不变。
- 公开笔记间可建立引用或衍生关系，源笔记必须属于当前用户，双方必须是同一议题且当前可见版本。源、目标版本均记录；更新版本显示历史关联，不提供旧版全文。撤回删除关联；管理员隐藏、用户屏蔽时双方不可见关系均不返回。
- 衍生研究按钮打开独立的私人笔记编辑器，不复制原文、不自动公开、不自动建立关系。作者保存自己的研究、主动发布后，从公开笔记关联入口手动选择来源并建立衍生关系。支持当前页可见笔记之间的关联；反向引用可打开其他页的关联笔记。
- 同议题当前页选择 2–3 篇当前公开笔记并排对照，不调用 AI、不评定优劣。移动端自适应排列。
- 共享文献库仅登记用户自填书目信息（题名、作者、年份、标识），并搜索、分页、移除本人条目。无全文上传、无自动验证、无外链跳转。文献支持原有举报、隐藏、恢复和用户屏蔽。每用户最多100条文献、每议题500条、每篇笔记100个引用关系。
