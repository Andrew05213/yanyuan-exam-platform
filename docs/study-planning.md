# 和知 AI 3.0 · 阶段 05 个性化学习计划与复习
基于 main b45684b（PR #12 已合并，主线 CI 46003691560 通过）。本阶段在原「今日学习」上扩展，不重建题库、学习报告、研究项目或笔记。用户要求下一阶段设计；草稿提交可执行规则核心，生产接入、数据库、界面尚未完成。不得自动合并或部署。
## 1 产品结构
- 今日计划：选择今天可用时间（含休息，默认建议60分钟，可设0休息日），选择任务来源，预览生成，明确确认后保存；显示实际计划、休息、剩余时间、推迟项及理由。单任务5–25分钟，任务之间至少5分钟休息，离线核心预算上限180分钟（只是此模块可安排额度，不是建议每日学习量）；不补罚未完成任务，不自动加时。
- 本周：自主选择日期、考试准备与研究比重，按日期逐日预览；未完成项仅进入待选择池，不自动堆叠。历史日计划锁定原版本，修改新版本保留真实完成记录。
- 复习中心：到期笔记、已保存错题组、专项训练、私人研究里程碑；选择再次学习/困难/掌握/跳过，由用户确认下次复习日期，复习等级不等于学术能力或录取概率；0/1/2/3/4对应1/3/7/14/30天基础间隔，困难或再次学习建议次日，跳过保持原状态。支持用户直接改期；无惩罚。
- 学习反馈：任务未开始/部分完成/完成/跳过；手动完成和客观已保存记录分别标记；计划条目与实际记录可建立显式关联，未保存、仅生成题卷、修改笔记时间都不算完成。空数据明确显示暂无，不伪造正确率或学习时长。
## 2 数据来源和证据
现有 GET /api/today 仅返回本人到期/最近笔记和档案摘要（到期最多8个，完整列表需服务端分页）；/api/learning-report 已有选择题实际作答、历史错题组、最新复练及截断标识，重复错题不能等同多次独立失败，截断不可外推；/api/study-state 已尝试/生成索引只是证据线索；/api/admissions 保留条件性资格及本人选校，优先训练 taskId，不把历史专业/语种推断为当年规则；/api/research-projects 只采本人有权限的项目里程碑，协作内容不能推导私人笔记。计划源由服务端按主体验证，绝不信任客户端 ownerId、sourceId、已完成标记或任意链接。原始笔记、答卷、成绩不发送 AI。第一版纯规则，不需要模型。
## 3 调度规则（已提交离线核心）
候选：id,kind,title,minutes,priority,sourceId,due（null或有效日期）；按到期优先、用户优先级、较早日期、稳定ID排序；未来日期暂缓，预算不足留待选择，不挤压休息、不把未完成任务自动滚入下一天。deadline 与 review due 后续在数据契约中分开（当前 due 仅表示最早可安排日，不能当报名提醒）；任务理由与来源可见。reviewNext 仅在真实反馈后给建议，不写笔记原 review_on 或档案。progress 仅统计任务状态，空计划 completion=null，不能作为成绩或效率评级。
## 4 生产接入（待实现）
独立迁移从最新编号追加：study_plan_settings(user_id,revision,preferences)、study_day_plans(user_id,day,revision,source_snapshot,rule_version,payload)、study_task_events(user_id,plan_id,task_id,event_id,kind,occurred_at,evidence_id)、review_schedule(user_id,source_kind,source_id,level,due,revision)。按本人ID复合键/唯一事件ID，限制读取/写入/分页，支持删除私人计划、反馈与复习状态而不删除原笔记或档案。保留来源失效提示，不在项目撤销或笔记归档后继续显示敏感摘要。原有归档与历史不改。
API /api/study-plans：GET 读取本人设置/计划和可核验候选；POST preview 无写入；PUT 保存/改期以 expected revision 原子比较；POST feedback 幂等写事件与版本条件更新（验证实际档案的归属与种类，标记手动或真实证据）；DELETE 本人计划/复习配置确认。沿用 principal、sameOrigin、readLimitedText、privateHeaders；禁止管理员越权、legacy fallback 访问新私人数据、跨账号读取、任意 URL 跳转。所有时间以 Asia/Shanghai 日期显示，UTC 存事件时刻。历史版本不能通过客户端重置状态或冒充客观证据。
UI：public/today.js 现有首页嵌入计划卡，保留原统计。扩展计划/复习工作台，支持预算和暂停、任务选择和调整、实际来源链接；移动端单栏，状态明确，错误可重试。复用任务及笔记原入口，源链接固定白名单并编码；LAN gateway 仅增加新API精确路径。生产接入需测试导航、会话切换、并发、源失效、空数据、预算、休息、日期跨月、回滚迁移及桌面/手机真实浏览器。不使用真实私人数据。
