# 全球文学研习
原有日本文学、文化、国别资料、笔记 ID 与权限保持不变。首页及浏览器标题统一为全球文学研习。重点语种：中文与日、英、德、法、西、俄语；北大相关其他语种只提供入门导读。语种按原作而非作者国籍或笔记语言；未标注的私人旧资料为未分类，可编辑补充。新增 30 个原创导读，不是文学全文，不冒充学术论文或官方考题。现有研究社区、跨语言专题及资料驱动出题继续使用真实笔记正文。图书链接仅供查找原文/版本；无链接的条目需要自行补充核对。统一检索支持原文书名、作者、中文名、主题、体裁、宽泛时期、阅读状态。各文学传统分期不同，宽泛分组不是全球通行文学史分期。材料 JSON 向后兼容，无数据库迁移，私有覆盖和删除保持独立。
