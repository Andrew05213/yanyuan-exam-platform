# 和知 AI 3.0 · 阶段 01 社区安全、邀请与权限
依赖 PR #3/#4；基于视觉分支 11904e4，独立堆叠 PR。不得在前两 PR 合并前将本 PR 合入 main。用户委托同学审核及决定合并，无需再次审批；助手不执行合并部署。

## 实施范围
- LAN 网关新注册默认仅凭单次邀请码；已有学习账号保留。管理员 /auth/governance 生成、撤销注册邀请、停用/恢复非管理员账号、查看近期日志；停用撤销网关会话，不删除学习数据。邀请码 SHA-256 摘要，随机 256 位，7 天默认，1–30天可调整，原子 SQLite 事务。
- D1 0016：research_memberships、research_invites、research_governance_audit、research_appeals。已有用户不自动获得社区资格。社区邀请码与注册邀请码独立，单次7天默认，数据库只保存摘要，D1 batch 条件兑换及审计。
- 研究社区各 API（议题、共享笔记、批注、引用、对照、共享书目、公开 AI 检索/分析）服务端强制成员准入；禁言可阅读/举报但不能发帖或批注；访问暂停仍可学习和使用私人 AI。主人可撤回自己的公开笔记。系统管理员原可信白名单不改变。审核员不能任命管理员、发邀请码或治理其他审核员。管理员不能通过治理读私人笔记。
- 学习用户、成员、审核员、系统管理员按独立角色；公开内容继续使用原研究者匿名别名，不显示账号邮箱。治理页可看自己最近处理依据和申诉结果，人工处理申诉；接受申诉后另行恢复成员状态，防止对旧版本申诉自动恢复新限制。
- 举报隐藏/驳回/恢复延用现有机制，并增加审计；无自动 AI 封禁、私聊或公开身份搜索。C 视觉品牌。
- D1 和网关分属独立数据库。完整账号停用仅覆盖中国版 LAN 登录；外部身份供应者的账号注册/停用不在该网关控制内。旧共享题库和附件现在也受社区成员准入及隐藏/双向屏蔽约束，访客保留基础静态训练题库，不再得到用户上传题库；本人仍能查看/撤回自己的分享。共享资料支持举报、审核隐藏与恢复，公开显示匿名别名。不要将面向陌生用户的部署视为已安全开放。还需完善内容级申诉/通知、审计保存期及清理策略、批量邀请、社区规则编辑、所有管理员操作（例如 Provider 配置）日志、并发撤销时正在执行的写请求的原子授权、治理后台可访问性及真实浏览器验证。现有治理页仅显示近期/分页记录，未做完整统计仪表盘。未实现邮箱验证和密码找回；初期只能受控可信成员试用。
