前置：阶段06 PR16已合并，main 0ba623e 的CI 46116013691通过。阶段07采用独立私有文献库（0024 单行CAS，最多300条、750KB），入口侧栏「学术文献」。元数据包括类型、原始署名、标题、出版年、刊物/书名、出版社、卷期页、DOI、HTTP(S)原出处、语言、标签、阅读状态和本人摘要。未知字段留空；DOI语法归一化不等于在线核验；不自动访问外部URL，不抓取付费/受版权保护全文。
已有目录由 app/literature/paper-citations.json 提供，保留原始引用字符串和出处URL；收藏不猜测篇名/作者/年份，明确目录来源待整理，结构化输出前由本人核对填写。手工元数据不标记为已在线验证。搜索标题、作者、标签、期刊、DOI、URL和原引文；分类、阅读状态、分页。重复DOI、相同URL或同标题作者年提示冲突；原始目录可保留原引文导出，结构化输出为GB/T和APA风格草稿及BibTeX、RIS，不声称严格符合所有刊物样式，不造缺失信息。通过原网址/doi.org核对出处。下载仅元数据文本，不下载原论文。
权限：principal、sameOrigin、readLimitedText、no-store、严格本人ID、版本CAS，读取与写入时检查有效本人笔记及本人项目，关联候选500笔记/200项目，截断提示；来源归档隐藏关联，保存清除不可见关联。删除记录不删除原资料。关联图谱新增reference节点、明确用户关联的note/project边与标签；不把元数据推定为学术论证或自动发布。图谱只使用书目字段，不读取私人摘要。无模型调用、无外部目录自动检索、无全文存储或文件上传；外部文献可通过合法出处查阅。后续阶段08才接入受控多语种研究工作流。
