# 各语种国别类口试组卷

组卷工作台 → 口试组合 / 专项 → 目标学校 → 目标语种 → 对应「国别类问题回答」。可按基础、进阶、挑战抽题，也可按该校训练配置生成整场口试。选择目标语种不强制用该语言作答：允许中文或英语，具备基础时可用目标语。

## 内容与边界

当前10校、87个学校/语种组合全部覆盖；语言目录含37个语种或专业方向。新增222道原创开放题，每个方向6题，基础、进阶、挑战各2题；原97项口试任务与笔试题保持不变，总计319项。每道新增题含准备/作答时间、参考组织、答题要点和追问。属于训练设计，未声称为真题、官方必考题或经实测校准的难度。通用参考组织并非完整事实性范文，作答例证需要自行核实。

梵文与巴利文作为一个独立方向，围绕南亚古典文献与文化交流；语言学、拉丁语等方向不强行对应单一现代国家。法语、西班牙语等覆盖相关语言地区。各校招生语种只沿用当前项目列表，此次不重新认证所有学校的本届招生资格。

北大训练选项按用户2026-11-01提供的本届备考名单改为：西班牙语、德语、法语、日语、阿拉伯语、朝鲜语、印地语、希伯来语、梵文与巴利文、俄语、乌尔都语。此名单标为用户提供、目标届2027、官方待核验；保留的2026官方链接仅为历史参考，不能证明该新名单。原北大葡萄牙语、泰语、印尼语选择从当前入口移除，其他学校相关语种保留。旧选择回退至学校默认语种，已保存试卷快照不修改。

## 实现与文件

- `content/school-tracks.json`：语种目录、北大名单与来源标记。
- `content/country-topics.json`：逐语种原创题目。
- `content/school_tracks.py`：生成标签、分级题目和学校范围，保留旧任务ID。
- `public/schools.json`：可直接使用的生成结果。
- `public/school-tracks.js`：显示历史/当前名单边界，按实际语种、题型、层级库存限制专项抽题数；筛选变化同步题量。
- `scripts/verify_school_tracks.mjs`：遍历87组合，验证专项、三档难度、整场组合、语种隔离、快照隔离、旧选择回退与题量控件。

重新生成：`python content/build_multischool.py`。仅新增静态训练内容与前端库存提示，不新增数据库迁移、密钥、API调用或管理员权限；身份与私有记录逻辑不变。原音分析仍依赖已有服务配置。
