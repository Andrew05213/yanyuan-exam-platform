# 个人研究项目

从主导航的「研究项目」创建项目、填写研究问题、维护里程碑，或关联自己已有的读书笔记。归档可恢复，删除项目保留原笔记。

有有效社区资格的用户可以交换协作编号。邀请需要对方明确接受，受邀者接受前只能看到项目名称。协作者可以查看已同意共享的项目简介和里程碑，并关联自己的笔记。项目和里程碑由所有者修改。私人笔记的标题和正文只对笔记本人可见，站点管理员同样受项目权限限制。

社区资格暂停或双方屏蔽会暂停协作访问。撤销或退出会移除对应的私人笔记关联，重新邀请须再次接受。网络边界继续由网关执行账号停用和会话撤销。

部署须应用 0019_research_projects。项目存储采用独立表和版本条件更新，核心状态验证与隔离数据库回归均纳入 CI。
