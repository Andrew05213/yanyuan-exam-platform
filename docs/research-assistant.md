# AI 学术研究助手
使用现有默认 Provider、OpenAI-compatible Chat Completions / Responses、加密凭据、允许的模型主机、原有用量与计费模块。没有新 API 密钥或模型依赖，无数据库迁移（新增 usage task research-assistant）。每账户24小时最多12次模型请求，含关键词扩展。配置缺失时只影响 AI，普通检索仍可用。

- 本地检索：社区共享笔记和书目只供受邀成员检索；私人检索只查当前用户未归档、未移入回收站的笔记。支持多语言关键词、按匹配词数排序、最多30条结果。SQLite lower 仅 ASCII 大小写折叠；非 ASCII 按字面匹配。可明确同意把查询词和目标语言发送默认模型扩展关键词，再用本地匹配检索。不是 embedding 向量检索或全文外部检索。
- AI：选择同一范围1至4份材料，三种任务（观点归纳、文献辅助分析、研究问题生成），指定研究问题和输出语言。服务端读取授权的精确版本，每份最多4500字符。预览显示实际材料、研究问题与目的模型。确认摘要绑定账号、范围、材料版本/片段、任务、问题、语言和 Provider 配置版本。调用前重新授权并核对摘要；完成后再核对权限与版本。模型请求不发送账号ID、邮箱、私人标签或复习记录；用户正文中仍可能有个人信息，应自行检查。
- 书目只是题名等用户提交信息，不冒充全文；不抓取外链、不调用外网搜索。输出结构化观点/依据、局限、问题；依据必须是所发材料的连续原文，未知来源与杜撰引文拒绝。引文核对不等同事实核验，结果标记未人工审核。
- 不保存提示词、正文或结果，不自动发布，也不读取未选择笔记。外部 Provider 自身的保留政策由实际配置决定，不能承诺上游不保留；撤回后的远端既有请求无法撤销。模型调用期间权限改变则不返回分析。
