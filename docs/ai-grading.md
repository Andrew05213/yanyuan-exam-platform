# 主观题 AI 批改接入位置

当前仅提供页面和接口占位，不调用任何 AI 服务，不需要密钥，也不会生成示例分数。

- 客观题继续由现有评分引擎对照参考答案核分。
- 作文、翻译和口试的默认人工填分入口已移除，显示“AI 批改暂未配置”。
- 已保存或导入的历史分数保留，标注为历史录入，不改称 AI 评分。
- 尚未批改的主观题保持待批改，整卷不会把缺失的主观分数当成零分或完整总分。
- 原有 ChatGPT 对话批改 JSON 导入保留为折叠入口，供已有的实际批改结果归档。

## 未来接入

`app/api/ai-grading/route.ts` 是统一接口位置，题型为 `writing`、`translation`、`oral`。

- `GET /api/ai-grading` 返回 `enabled: false`、`status: not_configured` 和 `score: null`。
- 登录用户 `POST /api/ai-grading` 返回 HTTP 503 和 `AI_GRADING_NOT_CONFIGURED`；未登录请求仍按私人接口规则处理。
- `public/ai-grading.js` 提供三个题型共用的占位组件。按钮刻意禁用，当前不会发起批改请求。

后续需要实现服务端模型适配、评分结果校验、页面请求和结果回写后，才能启用按钮。仅添加密钥不会自动启用批改。密钥应保存在服务器环境中。

接入时沿用 `lib/study-contracts.ts` 的作文原稿指纹、逐句覆盖、六维分数校验和首次批改保留约束。试卷中的主观评分应绑定题号、题目版本及实际作答，修改作答后须失效；保存并校验完整结果后再计入总分。

口试文字转写只能支持内容、逻辑和文字表达评价。若未来需要评价发音、流利度等语音表现，还需要单独接入音频输入与相应评分能力。
