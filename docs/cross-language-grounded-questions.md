# 第三阶段：跨语言专题与资料驱动出题

六个跨语言专题关联现有 36 个语言学科导读；可筛选比较视图、从专题创建社区议题、撰写私人笔记，并进入资料出题。按任一重点语言筛选社区议题时也包含对应跨语言议题。无新增数据库迁移。

材料选择来自现有私人笔记或社区可见公开笔记（同一次请求只能选一种权限范围，最多四份）；不将书目记录和机构检索入口当作全文。用户先预览最多每份 3600 字符、60 段的材料，确认发送到当前配置模型。预览绑定账户、题型、实际片段、材料版本和模型配置；调用前后重新核验权限及版本。

沿用 AI 出题配额和题型。每道题必须返回 1–4 条原文连续短引文、段号及来源编号，服务器验证引文真实存在并补入版本/来源信息，未经人工复核的答案始终待审核。个人题库写入时验证生成任务所有权、原始结果及材料现时访问权限；已保存的私人题目快照不自动发布。组卷解析与导出保留依据。引用匹配不等于原始文献与事实核验。现有资料目录并非完整论文库，不宣称自动外网全文获取。
